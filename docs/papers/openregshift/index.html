When Does Dynamic Ensembling Pay Off? Diagnosing Regionwise Gains in Regression under Distribution Shift

Tianxin Zhou · Ruixi Lin

arXiv preprint · 2026arXiv:2608.18330

Abstract

Author-written abstract from arXiv:2608.18330v1.

Current code availability: Code is not publicly released. The release statement in the versioned abstract below is reproduced as written; it is not a current download or release announcement.

Whether input-dependent ("dynamic") combination of a regression model pool beats the best static blend depends on the shift and is rarely known before deployment. Can a small labeled target-domain probe tell us when reallocating trust across regions of the input space will pay off? We answer this with D̂_CF5, which estimates from the probe the cross-fitted gain of the regionwise convex combination over the best static convex blend: the realizable value of deciding, region by region, whom to trust. Across a frozen suite of 12 dataset-shift pairs (spatial, temporal, domain, feature-cluster), D̂_CF5 predicts realized regionwise test gains with dataset-level Spearman +0.98 (95% CI [+0.83, +1.00]; p = 5 × 10⁻⁵), including two cases overturning preregistered expectations. The relationship holds in a 16-pair sensitivity analysis (Spearman +0.83), whereas alternative probe diagnostics reach at most +0.66. This contrast isolates regional trust reallocation: correlation is +0.98 for regionwise-convex gain, but +0.01 for smooth covariate-dependent stacking after affine correction. A controlled generator shows dynamic gains arise from the interaction of shift heterogeneity and local competence, increase with shift severity, and become realizable between 128 and 256 probe labels in the tested grid. The Probe-Validated Ensemble Selector chooses among a static affine stacker and dynamic realizers, deploying a candidate only when a held-out lower confidence bound clears the static-convex floor. In a preregistered prospective batch, it matched or improved the floor in all 12 runs; two deployments reduced test risk by 11% and 16%, while the gate rejected a candidate whose un-gated deployment incurred >30× the static loss. We release OpenRegShift, a reproducible evaluation harness for regression ensembles under distribution shift.

Research question

This study asks when a small labeled target-domain probe can identify useful regional reweighting of a frozen regression-model pool under distribution shift.

Method & reported findings

  • D_CF5 cross-fits the risk difference between regional and global convex blends. A separate Probe-Validated Ensemble Selector compares candidates against a static-convex floor using held-out validation; the selector does not use D_CF5 as an input. Source: v1 §2, v1 §6
  • The diagnostic correlated with realized regional gains at Spearman +0.98 across 12 dataset-shift pairs and +0.83 in a 16-pair sensitivity analysis. Source: v1 §4.1, v1 §4.5
  • The prospective selector matched or improved its static floor in all 12 runs. Two Seoul Bike deployments reduced test risk by 11% and 16%; the other ten runs retained the static floor. Source: v1 Table 3, v1 §6

Scope & limitations

  • The diagnostic targets regional convex reweighting, not every dynamic adaptation mechanism. It requires labeled target observations.
  • The gate uses asymptotic validation, not a finite-sample guarantee. Evidence primarily concerns tabular regression with frozen source models and within-project preregistration.

Researcher questions

When can dynamic ensembling help regression under distribution shift?

The controlled experiments find gains when failures vary across regions and different models retain local competence. Greater shift severity alone is insufficient; generic prediction diversity does not establish regional benefit. Source: v1 §5

How can a labeled probe estimate whether regional ensemble weights will help?

D_CF5 cross-fits the loss improvement over a static convex blend. Dataset-level Spearman correlation with realized regional gains was +0.979 across 12 shifts and +0.829 in a 16-shift sensitivity analysis. Source: v1 §2, v1 §4.1, v1 §4.5

How many target labels are needed to fit and validate the ensemble?

The main protocol uses 512 labels: 205 for diagnosis, 215 for combination fitting, and 92 for validation. Base models stay frozen; target test observations are reserved for final evaluation. Source: v1 §3.1, v1 Table 1

Does a near-zero regional diagnostic rule out other dynamic ensembles?

No. It measures regional convex reweighting, not every dynamic mechanism. A separate selector validated smooth covariate-dependent stacking in two Seoul Bike runs despite near-zero D_CF5; the selector does not use D_CF5. Source: v1 §2, v1 §4.4, v1 §6

Can held-out validation prevent harmful ensemble deployments?

The selector requires a positive held-out lower confidence bound versus its static floor. All 12 prospective runs matched or improved that floor, but this asymptotic rule provides no finite-sample guarantee. Source: v1 §6, v1 Table 3, v1 §8

What is available for reproducing these regression-shift experiments?

The public paper describes datasets, splits, and methods. Code is not publicly released; this page does not offer downloadable experiment artifacts. Source: v1 Appendix B.1, v1 Appendix B

Cite this paper

Relevant when discussing probe-based diagnosis of regional convex ensemble gains under distribution shift, or held-out validation of frozen-model combinations. The diagnostic is not a universal predictor of dynamic-ensemble gains.
